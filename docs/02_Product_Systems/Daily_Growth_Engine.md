# Overview

The Daily Growth Engine is Odyssey's personalized learning system.

Its purpose is to transform long-term goals into meaningful daily learning experiences by recommending lessons, practice activities, projects, and revision sessions based on each user's current progress and objectives.

Unlike traditional learning platforms that follow a fixed curriculum, the Daily Growth Engine continuously adapts the learning journey according to the user's goals, strengths, weaknesses, pace, and available time.

It answers one central question:

> **"What should I learn today to move closer to my goals?"**

---

# Vision

Learning should feel purposeful rather than overwhelming.

Every lesson should have a clear connection to a user's goals and demonstrate why it matters.

The Daily Growth Engine ensures that every learning session contributes to measurable personal growth.

---

# Objectives

The Daily Growth Engine should:

- Deliver personalized learning every day.
- Connect learning directly to user goals.
- Balance new concepts with revision.
- Encourage practical application.
- Adapt to individual learning speed.
- Build long-term mastery instead of short-term memorization.

---

# Responsibilities

The Daily Growth Engine owns:

- Daily learning plans
- Lesson recommendations
- Practice exercises
- Revision schedules
- Mini projects
- Learning streaks
- Mastery progression

The Daily Growth Engine does **not**:

- Store goals.
- Coach users.
- Manage task planning.
- Generate analytics.

---

# Outputs

The Daily Growth Engine provides:

# Learning Philosophy

Odyssey believes learning should always answer three questions:

- Why am I learning this?
- Where will I use it?
- What should I learn next?

Every learning activity should contribute to real-world growth.

# Learning Components

## Daily Lesson

Introduces one new concept.

Includes:

- Explanation
- Visual examples
- Real-world context
- Key takeaways

---

## Practice

Reinforces today's lesson.

Examples:

- Coding exercise
- Quiz
- Flashcards
- Writing exercise
- Simulation

---

## Mini Project

Encourages practical application.

Example

Learn Decision Trees

↓

Build a simple decision tree classifier

---

## Revision

Reviews previously learned concepts using spaced repetition.

The revision schedule adapts based on mastery and forgetting patterns.

---

## Reflection

Encourages users to think about:

- What did I learn?
- What was difficult?
- How can I improve tomorrow?

# Adaptive Learning

The Daily Growth Engine continuously adjusts based on:

- Learning speed
- Quiz performance
- Project quality
- Time available
- User confidence
- Revision history

Example

```text
User struggles with recursion

↓

Additional practice recommended

↓

Revision scheduled earlier

↓

Lesson difficulty adjusted
```
