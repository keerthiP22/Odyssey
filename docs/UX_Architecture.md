# Design Philosophy

Odyssey is **not** a task manager.

Odyssey is an AI-powered personal operating system.

The application should answer four questions whenever the user opens it:

1. What is my mission?
2. What should I do next?
3. How am I progressing?
4. What does my AI recommend?

The dashboard is intentionally minimal.

It should never become a page full of graphs and endless scrolling.

# Design Principles

Every component must answer one question.

"What action does this help the user take?"

If the answer is "none",

the component should not exist.

---

# Dashboard Rules

Never duplicate navigation.

Never show full analytics.

Never show large tables.

Never require endless scrolling.

Always prioritize action over information.
